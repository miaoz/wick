00

平台定位

Third platform, not a port

Linux 版是同一叠纸落在另一张书桌上:纸、墨、烛、章、单据全部沿用秉烛定稿(token 源 tokens-v2.css 不变);变的是桌面——窗口 chrome、磁贴、托盘、动效节奏都服从 Omarchy / Hyprland 的规矩。纸面身份只出现在内容里,窗口铬不伪造 macOS。

窗口铬
跟 Hyprland,不演 Mac。系统描边 + 圆角 + 磁贴间隙;无红绿灯、无假 titlebar、无无边框宣纸贴桌。窗口装饰是 OS 的地盘,Wick 不碰。
进度面板
浮动,不磁贴。layer-shell / 托盘弹出的纸签,结构对齐现行 Mac 面板(hero 大百分比 + 今日大烛痕条 + 周/月/年细条 + 页脚格言),出现在 Quickshell bar 的托盘区下方,点外即收。
日记主窗
可磁贴,四栏全开也成立。导航 / 日期列表 / 账册页 + 第四栏检查器(今日事件 + 盈亏月历)保留——黄历不撕页,但入栏。栏位全可独立开关(导航三态 × 检查器开关,共 3×2);磁贴半屏不够宽时自动先收检查器再收导航,落「仅列表 / 专注」,不硬撑四栏。
纸的物理
纸不透明。不用 Hyprland blur / 透明:秉烛的纸是有克重的东西,透了就不是纸。OS 侧自己的 bar 可以半透明,那是它的事。
字态落地
圆体(活数据)→ Inter + Noto Sans SC;宋体(印刷 / 存档)→ Noto Serif SC;单据等宽 → JetBrains Mono(Omarchy 默认等宽)。Qt 走系统字体,不内嵌。
四相位
弧光引擎原样保留。Omarchy 是暗色桌面,默认落在「暗 · 子夜」;亮 / 暗 / 跟随系统在设置里,四相位随一天流动——这是秉烛的魂,不为桌面风格砍掉。
修订 0.2
对齐现行实现而非旧定稿。① 复盘章 = 白文方章,字形恒为 ✓ / ✗,印泥随盈亏约定(✓ 盈色 / ✗ 亏色),盖下后 82% 透明浮条目右下;② 进度面板按现行 hero 结构重画;③ 检查器(栏内黄历)回到 1.0 范围——裁剪的只有贴桌物理彩蛋;④ 账册页按 JournalDaySection 重画:条目无卡片壳、发丝线分隔、页眉全件(大日期 / 农历 / 净盈亏 / 保存态 / 删除)。
盈亏约定
默认绿涨红跌,全界面跟随。色值只有两组:pnlUp = 朱砂、pnlDown = 黛青;约定只交换语义绑定。复盘章印泥、日期列表盈亏、单据数字、盈亏月历一律走约定;黄历的「宜 / 方印」永远朱砂,不参与交换。设置里可切红涨绿跌(A 股习惯),Linux 同一套。

03

设置 · 三端统一 IA

Settings, one IA across platforms

设置不再是三端各自一套。同一项设置,在 macOS / iOS / Linux 落在相同分类、相同顺序、相同文案;端间差异只允许一种:「这个平台没有这个东西」(标 —)。下表是统一后的目标 IA,也是三端各自的迁移清单。设置窗本身从 Mac 的「纸签第二态」改为独立小窗——Linux 没有菜单栏弹层里翻页的惯例。
