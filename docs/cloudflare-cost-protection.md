# Cloudflare 费用与愿望单保护

Workers 保持 Free。安装包继续放在公开的 `application-releases` 桶，愿望单邮箱和计数仅存于私有的 `wick-private` 桶，两者不得混用。

## 愿望单

- `WISH_BUCKET` 绑定 `wick-private`，不启用自定义公开域名或 r2.dev。
- 公开接口只返回人数，不返回邮箱；统计在边缘缓存 60 秒，查询参数不会产生独立缓存。
- 写入只接受 `wick.bitfroth.com` 的请求和白名单 Origin。pages.dev 和预览域名只读，防止绕过域名 WAF。
- 请求 JSON 最多 1 KiB，邮箱最多 254 字符。空字符串表示匿名 +1，错误 JSON 或无效邮箱不会产生投票。
- 重复邮箱不执行写入。R2 `onlyIf` 条件更新最多重试三次，避免并发覆盖；缺少绑定或存量数据损坏时拒绝写入。
- 每个 UTC 日最多接受 1,000 次新增登记/匿名投票，超出返回 429，次日自动恢复。这是防滥用的业务写入限制，不是账户费用硬上限。
- Cloudflare 免费 WAF 限流规则：同一 IP 在 10 秒内超过 3 次愿望单 POST 时阻断 10 秒。部署后需保持此规则开启。
- 页面仅在服务确认成功时标记已登记；失败可以重试。

查看登记数据使用 `scripts/view_wishlist.sh`，私有桶覆盖变量为 `WISH_R2_BUCKET`，与安装包上传的 `R2_BUCKET` 分开。

## 告警与保留

账户已配置首次计费 $0.01，以及 $1、$5、$10、$25、$50、$100 阈值告警；R2 存储、Class A、Class B 接近和达到免费额度时也有提醒，并有操作突增提醒。

告警不是停止计费开关。R2 为按量付费，限制应用入口、缓存和身份认证可以降低异常消耗，但无法保证账户级总费用上限。

存量安装包不自动过期，避免破坏旧版本下载链接。图片或安装包清理必须先核对引用，愿望单不得纳入公开资源生命周期规则。
